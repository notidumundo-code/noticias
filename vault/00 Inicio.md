# Noticias Globales

App personal (web + pantalla de inicio del iPhone) que junta cada día las noticias **económicas** y **políticas** relevantes, separadas en **Argentina**, **Región** (América Latina) y **Mundo**, y se actualiza sola cada pocos minutos.
